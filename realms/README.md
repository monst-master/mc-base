# MC BASE — Realmsモード（v4.4）

GitHub Pages: https://monst-master.github.io/mc-base/

## 大切な仕様
Minecraft Realmsでは、BDS用のHTTP通信モジュール `@minecraft/server-net` を利用できません。ゲーム内のプレイヤー座標、チェスト、資材、ブロック設置イベントをMC BASEへ**自動送信する機能はありません**。
- 出典：Microsoft公式 https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server-net/minecraft-server-net

## 使い方
1. DiscordでMC BASEにログインし、承認済みワールドを選択。
2. メニュー「🛰️ Realms座標共有」を開く。
3. Minecraftのプレイヤー名、ディメンション、X/Y/Zを入力。
4. 他のメンバーへ座標を公開する場合だけ「承認済みメンバーに座標を共有する」にチェックして保存。
5. クラウド上の座標データが約12秒ごとに更新され、MC BASE内部のシードマップ（座標グリッド）と統合版ワールドマップに手動位置が表示される。
6. 「活動記録」へ建築・採掘・探索・資材などの進捗メモを追加できる。これらも手動記録。
7. 「建築物の座標をマップへ登録」で管理者が既存の座標メモを追加できる。

## 注意
- 座標表示には最後に**手動入力した座標**を使用。「オンライン中」「GPS追跡中」の意味ではありません。
- 他の承認済みメンバーには、本人が共有オンにした座標だけが表示されます。「共有をオフ」で即時非公開にできます。
- Realmsゲーム側の資材所持数・チェスト在庫は自動取得されません。既存のMC BASE「資材管理」へ必要に応じて入力します。
- マップの外部シードマップiframeにはピンを重ねず、MC BASE内部の座標グリッド・画像アップロード式の地図に表示します。
- 「📡 サーバー活動・現在地」はBDS専用なのでRealmsでは利用しません。
- 自動同期を行いたい場合、BDSへの移行等、サーバー側から外部API送信できる仕組みが必要です。Realmsのままでは対応できません。
- 承認済みメンバー向けSupabaseテーブルはRLS有効。非承認者は参照不可。
